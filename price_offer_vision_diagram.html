🎯 고객 인지 변화 목표 (North Star)

"번개장터에서 흥정하는 게 자연스럽고, 공정하고, 빠르다"

진지한 구매자와 판매자가 시장 정보를 바탕으로 빠르게 적정가에 합의하고 즉각 거래를 완결하는 경험
📌 협상의 본질 — 정의부터

지금 번개장터 가격제안은 "제안"이지 사실 "협상"이 아닙니다. 진짜 협상이란: 구매자의 최대 지불 의향가(WTP, Willingness To Pay)와 판매자의 최소 수락가(Reservation Price) 사이의 Gap을 줄여가는 과정입니다.

구매자 WTP
↑ 거래 가능 구간
판매자 최저가
현재 문제: Gap을 좁히는 수단이 없음. 구매자가 숫자 하나 던지고 끝 — 오프라인 "흥정"의 본질이 빠져 있음
현재 피쳐의 구조적 문제 3가지
① 정보 비대칭
적정가 모름 → 낮게 찔러봄
구매자 WTP와 판매자 최저가 사이 Gap을 좁힐 수단이 없어 찔러보기가 합리적 전략이 됨. 찔러보기는 개인 문제가 아니라 정보 구조의 문제
② 약속 비용 = 0
제안 비용 없음 → 남용
온라인에서는 사회적 비용이 없어 진지함을 증명할 수단이 부재. 비용 없는 행동은 남용되고 판매자·구매자 상호 불신 구조를 만듦
③ 피쳐 신뢰 부족
응답 부담 + 기대 낮음
OFF 변경 판매자의 89.7%가 가격제안 경험 없이 OFF 설정. 스팸 때문이 아니라 "이 기능 쓸 이유를 못 느낀다"는 신호
단계별 로드맵
Phase 1 — 재협상 허용 + 기본 안전장치
전체 청사진의 약 30%
✅ 현재 프로젝트
재협상 허용
  • 1회 → 2회 제한 완화
  • 재제안 사유 입력 UX
  • 재제안 히스토리 표기
  • 일일 5회 한도 유지 (재제안 포함)
→ Gap 좁히기 첫 단계
판매자 보호
  • 차단 옵션 (상품×유저 단위)
  • OFF율 가드레일 모니터링
  • 배너로 정책 변경 인지
→ 약속 비용 부분 해소
어뷰징 방지
  • 미결제 N회+ → 제한
  • 패널티 예고 노출
  • 신뢰도 기반 제한 (초기 버전)
→ 피쳐 신뢰 회복 시작
CRM 타겟 푸시
  • Signal A 유저 98K명
  • OFF 판매자 유도
  • 역제안 만료 재제안
  • 딥링크 개인화
→ 즉각 행동 유도
전체 청사진의 약 30%
Phase 2 — 가격 발견 + 신뢰도 시스템
배포 후 데이터 기반 · 전체 청사진의 약 65%
🔜 중기
시장가 가이드
  • 유사 상품 최근 거래가
  • 평균 제안가 표시
  • "이 가격이면 X일 안에 팔려요" 가이드
  • "이 상품 평균 제안가 XX원" 구매자 안내
→ 정보 비대칭 해소
신뢰도 시스템
  • 거래완결율 공개
  • 신뢰도별 협상 자유도
  • 판매자에게 구매자 신뢰도 표시
→ 약속 비용 구조화
중간가 수락
  • "중간에 만납시다" 버튼
  • 양측 동의 시 자동 성사
  • 결제 수단 사전 연동
  • 수락 즉시 자동 결제
→ 협상 완결 속도 ↑
판매자 도구 강화
  • 자동 수락 가격 설정
  • 최소 수락가 비공개
  • 다중 제안 일괄 관리
  • 시간 알림 재설계
  • 판매자도 먼저 제안 가능
→ 판매자 피로 해소
전체 청사진의 약 65%
Phase 3 — 자동화 협상 + AI 중개
전체 청사진의 100%
🔮 장기 비전
양방향 가격 범위 설정
  • 판매자: 최소 수락가 설정 (비공개)
  • 구매자: 최대 의향가 설정 (비공개)
  • eBay Best Offer 방식
→ 정보 비대칭 근본 해소
AI 협상 중개
  • 양측 범위 겹치면 자동 매칭
  • 최적 합의점 제안
  • 협상 없이 이용자 성사
→ 협상 비용 = 0에 수렴
시장 투명성
  • 실시간 시세 형성
  • 수요-공급 기반 가격 발견
  • 번개장터 = 가격 기준점
→ 플랫폼이 시장 그 자체
