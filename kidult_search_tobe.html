검색어 기반 카테고리 매핑 (선행 로직)

왜 필요한가

  • 카테고리별 탐색밴드는 "이미 카테고리 검색결과 화면에 들어와 있다"는 전제로 설계됨. 실제 유저는 카테고리를 먼저 고르지 않고 검색창에 바로 키워드를 입력하므로, 검색어 → 카테고리 매핑이 선행되어야 탐색밴드가 의미를 가짐.
  • 단일 쏠림(예: "루피 피규어" — 원피스/피규어 의도가 명확)은 자동 적용, 중의성(예: "건담" — 프라모델·피규어 둘 다 존재)은 추천 칩으로 되물어야 함.
  • 다만 현재도 앱에 카테고리 추천 칩 자체는 존재함 — 우리 제안은 이 기존 요소를 "선택하면 더 정확해진다"는 인지가 되도록 강조하고, 선택 시 카테고리별 패싯밴드가 바로 이어지도록 연결하는 것.

카테고리별 탐색밴드 (검색어+카테고리 조합 화면)

이 화면의 전제 시나리오

  • ① 유저가 특정 키워드를 검색 → ② 키워드 기반 카테고리가 자동 적용되거나 추천 넛지를 통해 선택됨 → ③ "키워드 + 카테고리" 조합으로 검색결과가 리스팅된 상태가 지금부터 보여드리는 화면입니다.
  • 따라서 상단에는 실제 검색어가 그대로 남아있고, 카테고리 추천 영역에는 이미 카테고리가 선택된 상태(✕로 해제 가능)이며, 그 아래 카테고리 전용 패싯밴드가 이어집니다.
